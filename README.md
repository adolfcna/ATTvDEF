# ATTvDEF

> A structured knowledge base focused on **Attack vs Defense** concepts in cybersecurity.

ATTvDEF is a curated documentation site designed to explore offensive and defensive security concepts side by side.  
The goal is simple: understand how attacks work — and how to stop them.

---

## 🌐 Live Website

The full documentation is available here:

🔗 https://adolfcna.github.io/ATTvDEF

Reading it through the website provides better structure, navigation, and context.

---

## 🎯 Purpose

This project aims to:

- Break down real-world attack techniques
- Explain defensive countermeasures clearly
- Connect offensive tactics to practical mitigation strategies
- Provide structured notes for security practitioners

It is built for learners, defenders, and offensive security enthusiasts who want practical clarity — not noise.

---

## 📚 What You'll Find

- Attack techniques and methodologies
- Defensive strategies and detection logic
- Concept explanations with practical perspective
- Structured and continuously expanding content
