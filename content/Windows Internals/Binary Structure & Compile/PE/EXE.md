> [!info]+ 🖥 Simple C++ Program: Hello World
> Example of a minimal C++ program that prints "Hello world" and waits for user input:
> ```c++
> #include <stdio.h>
> #include <stdlib.h>
> 
> int main(){
>     // Print message to console
>     printf("Hello world\n");
>     
>     // Wait for user to press Enter
>     getchar();
>     
>     return 0;
> }
> ```
> Notes:
> - `printf("Hello world\n");` → prints text to the console  
> - `getchar();` → waits for user input so the console doesn't close immediately  
> - `return 0;` → indicates successful program termination
